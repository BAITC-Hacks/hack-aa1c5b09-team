# Ясно — от потребности к решению

MVP команды «А да нууууу». Фронтенд находится в [`frontend/`](frontend/); сервер и ИИ могут разрабатываться независимо.

Потребитель описывает идею → уточняет задачу с ИИ → проверяет карточку → публикует заявку → обсуждает предложения → выбирает исполнителя.

## Запуск

Нужен Node.js 22.12+ (проверено на Node.js 24).

```sh
cd frontend
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173 и нажать **«Открыть демо»**. Также можно зарегистрировать новый демонстрационный аккаунт — у него будет пустой список заявок.

По умолчанию используется `mock` без сервера. Данные сохраняются в браузере. Демонстрационные ИИ и исполнители отвечают по заранее заданному сценарию. На опубликованную заявку автоматически добавляются три демонстрационных предложения.

Подробности запуска и проверки: [frontend/README.md](frontend/README.md). Контракт для команды: [frontend/API.md](frontend/API.md).
